# Student-Grade-Calculator

A simple Python project to calculate student marks, percentage, grade, and result.

## Features

- Takes student name as input
- Takes marks for 5 subjects
- Calculates total marks
- Calculates percentage
- Assigns a grade
- Displays the final result

## Technologies Used

- Python

## How to Run

1. Open `student_grade.py`
2. Run the Python program
3. Enter the student name
4. Enter marks for each subject
5. View the total, percentage, and grade

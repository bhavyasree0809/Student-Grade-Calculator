Student Marks Management System 🎓

📌 Project Description

The Student Marks Management System is a Python-based application that helps users record student marks, calculate percentages, assign grades, and determine pass or fail results.

✨ Features

- Add student names and subject marks.
- Support multiple subjects.
- Validate marks between 0 and 100.
- Calculate total marks, average, and percentage.
- Assign grades automatically.
- Determine pass or fail based on subject marks.
- Generate individual student report cards.
- Display class performance summaries.
- Run diagnostic tests to verify grade calculations.

🛠️ Technologies Used

- Python 3
- Dictionaries and lists
- Functions
- Loops and conditional statements
- Exception handling

🚀 How to Run

1. Open an online Python compiler such as Programiz.
2. Create a file named "main.py".
3. Copy the Python source code into the file.
4. Click Run.
5. Select an option from the main menu.

📋 Menu Options

Option| Function
1| Add Student Marks
2| View Student Report
3| Class Performance Summary
4| Run Diagnostic Tests
5| Exit

⚠️ Limitations

- In the simplified online-compiler version, student records are stored temporarily in memory.
- Records are lost when the program restarts.
- The application uses a command-line interface.
